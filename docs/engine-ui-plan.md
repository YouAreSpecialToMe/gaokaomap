# 推荐引擎 × 画卷地图 合体计划

> 2026-06-12。目标:6 月 23 日出分日前,画卷地图上"输入省/科类/分数 → 真实冲稳保点亮"全链路可用。

## 北极星体验
考生打开地图 → 选省份+科类+输入分数 → 一分一段换算位次 → 画卷上冲稳保学校点亮(红橙绿描边脉动)→ 点学校看专业级建议与近三年线 → 一键巡游讲解。

## 架构(三层,全部已有雏形)

```
画卷前端 gaokao-map.html        ←  fetch /api/*
极小 API(Python 只读 SQLite)  ←  demos/serve-api.py(新,~80 行)
gaokao.db 2.1GB                 ←  私有仓库分发,服务器 git pull
```

发布形态:与 agentsfeed 同机的 Windows 自托管(nginx 反代 /api,前端静态)。

## 红线与对策
| 风险 | 对策 |
|---|---|
| 个人信息合规 | 分数不落库不留存:前端→API 即算即弃,无账号无 cookie |
| 数据准确性责任 | 每条建议强制带年份与"仅供参考";艺体类 v1 不出推荐 |
| 地图边界 | 现有标准边界描线;公开推广前做审图评估 |
| 性能 | 只读 SQLite + 现有索引,单查 <50ms;API 进程内 LRU |

## 明确不做(v2 再说)
L4 问卷模型、城市择校页、AI 文案解读、账号/收藏、艺体类推荐。
