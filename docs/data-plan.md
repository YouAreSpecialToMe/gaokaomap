# 高考升学地图 · 真实数据规划

> 2026-06 制定。原则:官方公开数据优先;浙江试点先行;每层数据独立可用、增量上线。

## 数据全景(六层)

### L1 院校主数据(地基,工作量小)
全国普通高等学校 **~2820 所**(本科 ~1300 / 高职专科 ~1500)。

| 字段 | 来源 | 备注 |
|---|---|---|
| 名称 / 教育部标识码 | 教育部《全国高等学校名单》(每年 6 月更新, 官网公开) | 唯一主键用标识码 |
| 省 / 市 / 区 | 同上 | |
| 办学层次 (本/专) / 公办民办 / 中外合作 | 同上 | |
| 985 / 211 / 双一流(147 所) / C9 / 国防七子 | 教育部双一流建设名单(公开) | 旗子颜色分级 |
| 院校类型(综合/理工/师范/医药/财经/政法/农林/民族/艺体/军事) | 阳光高考院校库 | 筛选 chips |
| 主管部门(部属/省属) | 名单自带 | |
| 主校区经纬度 | 高德地理编码 API(免费额度足够)+ 人工校对 top200 | 多校区:主校区为准,字段留 campuses[] |
| 校徽 / 简介 / 校训 | 各校官网 | ⚠️ 校徽商用有版权风险,正式版需评估 |

### L2 录取数据(核心资产,工作量最大)
粒度:**(院校, 省份, 年份, 科类/选科, 批次, 专业组/专业)**

| 数据 | 用途 | 来源 |
|---|---|---|
| 院校/专业组投档线(分数+**位次**) | 冲稳保推荐的根基 | 各省教育考试院官网(公开,格式各异) |
| 专业录取线(最低分/位次) | 专业级推荐 | 考试院 + 各校本科招生网 |
| 招生计划数(校×省×专业) | 概率模型权重 | 考试院发布的招生计划 |
| **一分一段表**(省×年×科类) | 分数↔位次换算、跨年对齐 | 考试院,每年放榜日发布 |
| 批次线/特控线 | 资格判定 | 考试院 |
| 选科要求(物化捆绑等) | 新高考过滤 | 阳光高考"选科查询"系统 |

年份覆盖:**最少 3 年(2023-2025),理想 5 年**。
⚠️ 商业平台(掌上高考/夸克)数据不可爬用;考试院公开信息可用并注明来源。

### L3 专业数据
- 教育部《本科专业目录(2024)》:12 门类 / 93 专业类 / **816 专业**(6 位代码)——公开
- 专业介绍 / 核心课程 / 学制学位:阳光高考专业库
- **学科评估**(第四轮公开 A+~C-)+ 双一流学科 + 国家级一流本科专业建设点——"王牌专业"标签的依据

### L4 兴趣测评模型(自建)
- 方法论:霍兰德 RIASEC(公有领域)做骨架,MBTI 风格的题面做体验
- 需自建两张映射表:**题目→六维得分**(30-40 题)、**专业类→RIASEC 画像**(93 专业类逐个标)
- 这是产品创意层,无外部数据依赖,但需要教育领域 know-how 校准

### L5 城市数据(差异化亮点)
- 已有:省市边界(DataV)、地形、水系、街巷瓦片
- 需补:城市标签(一线/新一线)、产业关键词(杭州=互联网、合肥=量子/新能源)、平均生活成本档位——量小,手工维护 50 城即可
- ⚠️ 正式版地图边界合规:自然资源部标准底图/审图号

### L6 衍生计算数据(管线产出)
- 等效位次(跨年对齐后的标准化位次)
- 冲稳保概率参数(按历年位次波动拟合;v1 可用规则:冲=位次差 -15%~0,稳=0~+20%,保=+20%~+50%)

## 浙江试点的最小闭环(Phase 1)

浙江是最佳试点:专业平行志愿(数据粒度直接到专业)、考试院数据规范(Excel 公开)。

需要 5 个数据集:
1. 教育部名单 + 双一流标签(全国,1 个文件)
2. 全国本科院校坐标(geocoding 批量 + 校对)
3. 浙江普通类一段/二段**平行投档分数线表** 2023/2024/2025(每年约 3 万行,含专业+位次)
4. 浙江**一分一段表** ×3 年
5. 本科专业目录(代码↔名称↔门类)

体量:约 10 万行,Postgres 轻松承载。预计 1 周内可全部入库。

## 库表草图

```sql
universities(id, moe_code UNIQUE, name, province, city, level, ownership,
             type, tags text[], lng, lat, intro, motto)
majors(code PK, name, category, class, degree, years)
admission_lines(id, uni_id→universities, province, year, subject_group,
                batch, major_group, major_code→majors NULL,
                min_score, min_rank, plan_count, source_url)
rank_tables(province, year, subject_group, score, count_at, cum_count,
            PK(province,year,subject_group,score))
batch_lines(province, year, type, score)
uni_major_strength(uni_id, major_class, grade)   -- 学科评估/一流专业
riasec_majors(major_class, r,i,a,s,e,c)          -- L4 映射
quiz_questions(id, text, dim, weight)
cities(name PK, tier, industry_tags text[], cost_tier)
```

## 阶段排期

| 阶段 | 内容 | 产出 |

## 合规红线
1. 只用政府/教育部门公开数据,页面注明出处
2. 不爬商业平台(掌上高考/夸克/百度)
3. 用户分数/位次=敏感个人信息:最小化收集、不默认上传(个保法)
4. 公开发布的中国地图需审图合规
5. 校徽/校门照片版权逐项确认
